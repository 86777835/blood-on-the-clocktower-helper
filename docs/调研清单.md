## 定位

**说书人手机上的“记录本 + 流程清单”**。身份仍然用实体 token 线下抽，夜里照常用手势，投票照常举手。网站负责记下说书人容易记错、记漏的东西；终局后把这些记录公开出来，方便复盘。

玩家手机只能看到公开信息、剧本角色表和自己的笔记，看不到任何身份。

两边调研结论一致：不替代说书人，只做“魔典解决不了、得靠脑子或纸记”的事。参考 EN §4，以及 CN §5 里 29 赞的反对 AI 主持评论。

### 隐藏信息分三档，在服务端过滤

- **说书人**：凭密钥拿到完整状态。
- **玩家**：每人一个随机令牌，只额外拿到自己的笔记。
- **公开视图**：只有存活状态、幽灵票、提名和票型。

终局前，玩家和公开视图都拿不到任何身份、标记或日志。测试方法沿用惨剧轮回的做法：检查每个非说书人连接收到的每一帧，并检查玩家之间看不到彼此的笔记。

## 不做

| 功能 | 原因 |
|---|---|
| 手机发身份、抽身份 | 线下抽实体 token 的仪式感是共识：CN 43 赞评论说改成抽牌后“感觉立刻上来了”；小程序抽签会被质疑“不够随机”；Pocket Grimoire 的电子发身份被嫌别扭，用户又改回实体 token（EN §4-5） |
| 手机投票 | 举手或轮盘投票是核心体验，中英文社区都没人要求搬到手机上（EN §4-3、CN §5-5）。要的只是“说书人记下票型”，也就是第 6 项 |
| 夜里往玩家手机推信息 | 夜里手机亮屏或振动本身就会暴露谁醒了（工具调研） |
| 自动算信息、自动裁定、AI 主持 | 社区强烈认为说书人不可替代（CN §5-2）。TPI 政策也写明，试图对角色互动给出权威裁定的辅助工具不会获批 |
| 计时器 | 证据弱（CN ⑩ 只有零星提及），还有说书人反对计时，认为时间是用来平衡局势的手段（EN 痛点 9）。手机自带的计时器就够 |
| 私聊组织 | 国内习惯是面对面拉微信群，或者走开去聊，线下就能解决（CN ⑥） |
| 自定义剧本、JSON 导入、实验性角色、华灯初上等扩展 | 版权风险和数据量都大，集石官方魔典已经能做。首版只做实体基础盒里的三个剧本 |
| 选角平衡建议、推荐板子 | 没有官方依据，容易误导 |
| 离线模式 | 系列网站都是在线房间。做好断线重连和状态恢复就行（CN ⑪ 提过弱网问题） |

## 需要你拍板：合规风险

TPI《社区内容政策》（[原文](https://bloodontheclocktower.com/pages/community-created-content-policy)，2026-11-04 核对）里跟我们相关的几条：

- 必须**免费**，必须**明确标为社区作品**，**不得上架任何应用分发平台**。我们是免费网页，这几条都满足。
- “不得做与 TPI 已有或已宣布的产品**同类**的产品或服务”。说书人、玩家辅助工具**逐个审核**，“与官方资源直接竞争，或试图对角色互动给出权威裁定的”不会获批。
  - 第 3 项“魔典状态”和官方 botc.app 的本地模式、集石官方中文魔典有重叠。
  - 规则助手可能被看作“给出裁定”。
- Reddit 上有一条单一来源、没有核实的消息：2025-06，一位做免费中文魔典 **App** 的作者说，被自称代表集石的人以侵犯著作权和不正当竞争为由要求下架。该作者同时说中文魔典网站没有问题。

**我的建议：照常做，同时降低风险。**
- 页脚写明“非官方玩家工具，与 TPI、集石无关”，不上架应用商店，不收费，不放广告。
- 角色只用中文名（取自集石百科），能力用自己的话写简述，图标用文字徽章（角色类型配色 + 首字），不用官方图标和美术。
- 规则助手只依据本站自写的规则摘要回答，每次回答都注明“以本局说书人裁定为准”，并拒绝对具体角色互动下定论。

另一个选择是先写信问 TPI（butler@thepandemoniuminstitute.com）或集石，等他们答复再做。这样更稳妥，但要等。
