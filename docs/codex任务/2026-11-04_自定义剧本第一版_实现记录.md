## 取舍及边界

- 未扩充官方角色池，仍为现有 72 个角色。内置三个剧本只读；复制后成为独立自定义定义。
- 未知 ID 采用“列出并拒绝导入”，不做自动移除或猜测替换。
- 只支持本次需要的英文格式字段及 `jinxes`、完整 `_meta.firstNight/otherNight`。图片、logo、background、almanac、special、全局提醒、bootlegger 等未支持字段明确报错，请用户明确移除后重试；任何 URL 都不请求。普通名称／能力中的 HTML 和 URL 按文字显示。
- 缺少 `_meta.name` 时明确要求补充；自制角色的两类夜序必须明确提供数值，0 表示不行动。不把缺字段猜成不行动。导入的整表夜序必须完整覆盖本夜行动角色和公共步骤，避免遗漏造成错误顺序。
- 为准确表达“在某角色之前／之后”，编辑器保存明确的 ID 夜序数组，支持相同数字夜序中的位置选择，并提供预览；新增官方角色按官方序号寻找插入参照，保留已有相对顺序。
- 导出下载要求至少 4 个角色，加 `_meta` 共 5 项，以满足官方 Schema 的数组最小长度；站内可保存更小定义，人数不足仍给提示。混合导出样例已使用 Python jsonschema 对[调研固定版本官方 Schema](https://raw.githubusercontent.com/ThePandemoniumInstitute/botc-release/f10cd02e3401af227ce406287eaae7bb99a06a42/script-schema.json)验证通过。
- 自制角色的 setup 只提醒人工确认，不执行能力。原有提名／投票限制、单座位单角色和 5–15 人范围保持不变；没有新增运行时阵营编辑、重复身份、特殊投票裁定或全局提醒系统。
- 相克支持导入、保留、导出，并按整个剧本的角色对公开展示；没有新增相克表单或补齐官方相克数据库。
- 本机最近列表最多 10 项，清理浏览器会丢失；可下载 JSON 备份。保存修改会重置尚未开局房间的袋子和座位角色，界面有说明；已开局不可修改定义，已归档快照不变。
