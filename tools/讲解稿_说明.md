## 术语对照（以百科为准）
- Recluse = 陌客（不是“隐士”，百科里“隐士”是 Hermit）；Mayor = 镇长（不是“市长”）。
- 死人那一票，百科正式叫“投票标记”；“幽灵票 / 死人票”是玩家俗称，英文 Glossary 也没有收 Ghost vote 这个词条。稿子写成“投票标记（大家常叫幽灵票、死人票）”。
- Execution = 处决；“on the block / about to die” = 即将被处决；Exile = 流放（旅行者专用，本站不支持）。

## 中英差异 / 拿不准的地方
- 【待核实】**人数配置表**：中英两边的网页都没有把 5–15 人配置写成文字，都说“见旅行者列表（实体配件）”。稿子里的数字是常用的标准表，只有 7 人（5/0/1/1）和 15 人（9/2/3/1）两行能在百科“男爵”页的例子里对上。上线前请对照实体旅行者列表逐行核对。
- 【待核实】**6 人及以下没有伪装角色**：英文 Glossary 和百科术语汇总都写明“爪牙信息 / 恶魔信息只出现在 7 人及以上的局”，百科说“恶魔信息”包括 3 个不在场角色，所以推出 5–6 人局恶魔不拿伪装角色。这是根据定义推出来的，两边都没有单独一句话直接这么说。
- 【待核实】**“从被提名者左手边开始数票”**：官方原文只说“顺时针”，并且被提名者最后数（百科：规则概要；Wiki：Glossary “Vote”）。没有提到“左手边”。坐成一圈面朝里时，顺时针下一位一般在左手边，但稿子只写了“顺时针”。
- **Rules Explanation（英文）没提“每天只能提名 / 被提名一次”**，这条规则在英文 Glossary 的 Nominate 词条和百科“提名”页里有，稿子按这两处写。
- **投票至少要 1 票**：百科“投票”页多写了一个条件：至少得 1 票，主要是给军团、窃贼、法官这类能让票数变成 0 的角色用的。这三个都不在基础盒的提名环节里，稿子没写。
- **处决后还能不能用白天能力**：百科说由说书人决定，FAQ 照写“由说书人决定”。
- **红唇女郎 / 贞洁者**：FAQ 加了“没醉酒中毒 / 能力正常”的前提，依据是百科“红唇女郎”页（“前提是能力正常生效”）和“贞洁者”页。更复杂的互动（比如间谍、陌客被当作别的角色时怎么判）都没写，属于说书人裁定范围。
- 英文 Wiki 只能看到工具摘要，看不到原文。凡是写成（Wiki：…）的条目，内容都和中文百科对得上；两边说法不一样的地方，都已在上面列出。
